# Sample documents (fictional)

Three made-up documents for testing setup from documents: a grant agreement (Word), a logframe and a budget (Excel), for the "SANDBOX Sample Orchards Project". The donor, the agreement and every figure are invented. Use them to try setup without real project files.

Two made-up spending exports for testing spending import from any spreadsheet (Report, "Import Finance's budget against actual"), matched to the same sandbox project's budget lines (SSOP-2027):

- `quickbooks-transactions-jan-2027.csv`: a QuickBooks "Transaction Detail by Account" export for January 2027, with title rows, subtotal rows and one amount column. Some accounts carry the budget code (A-111), others only a matching description, and one (bank charges) matches no line.
- `netsuite-gl-feb-2027.xlsx`: a NetSuite GL detail export for February 2027, with separate debit and credit columns and a currency column.

The payees ("Example Wire Traders" and so on) are invented.
